# SC4021-Information-Retrieval
AY 25/26 Sem 2, SC4021 Information Retrieval

🚀 Getting Started
Follow these steps to get the project running on your local machine.

Prerequisites
Make sure you have Docker Desktop installed:

Download Docker Desktop

Installation & Running
Clone the repository:

Bash
git clone https://github.com/Dangomimikyu/SC4021-Information-Retrieval.git
cd SC4021-Information-Retrieval
Start the application:
Run the following command in the root directory. This will build the images and start the Frontend, Backend, and Solr containers.

Bash
docker-compose up --build
Access the apps:

Frontend: http://localhost:5173

Backend API: http://localhost:8000

Solr Admin UI: http://localhost:8983
